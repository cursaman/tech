# TECHCARE 복합기 기술지원

Samsung MultiXpress MX 시리즈의 오류코드 검색과 현장 해결 가이드를 제공하는 기술지원 홈페이지입니다.

## 주요 기능

- 오류코드와 증상 통합 검색
- 문제 유형별 분류
- 단계별 자가 점검 안내
- ADF 줄 발생 및 M2-1317 이미지 가이드
- MX·MXPRO 오류코드 PDF 다운로드
- PC·모바일 반응형 화면

## 홈페이지

https://techcare-mfp-support.jclee7381.chatgpt.site

## 로컬 실행

```bash
npm install
npm run dev
```

배포용 빌드는 `npm run build`로 확인할 수 있습니다.
